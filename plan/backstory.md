# Backstory register

What the three and the people around them were before the story opens: habits, history, opinions, preferences, memories, the shape of an ordinary day. A scene's map spends these by id in its `TEXTURE` field (`process/methodology-theory.md` §4a), and drafting draws on this file instead of inventing color on the spot, because invented color is inconsistent color.

**This file owns only what no other canon file states.** Heights, senses, upgrades, families, Yara's death, the masks and the voices live in `plan/milieu-brief.md` §9, `plan/minor-characters.md`, `plan/character-arcs.md`, `plan/voice-sheets.md` and `plan/humor-plan.md`, and a map cites those files directly. Restating them here would only give a drafter two versions to choose between.

**Consistency is the rule that governs spending.** An item is the same in every scene that touches it. The scene list after an item is where the prose already spends it; *revise* marks a scene whose current wording disagrees with the item and will be brought into line when that scene is revised. A new item a scene needs is proposed to Daniel and added here before the scene uses it.

**Gray, not black and white.** These are people, so the items say *often*, *most*, *rarely* and *a few times* where a summary would reach for *always* and *never*. Where an item does say *never*, it is a fact about one thing that did not happen.
